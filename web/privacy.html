Общак — приложение для совместного учёта личных расходов и доходов. Этот документ описывает, какие данные приложение обрабатывает, зачем и кому их передаёт. Коротко: рекламы нет, аналитики нет, данные не продаются и не передаются никому, кроме перечисленных ниже технических служб.

Мы не спрашиваем, кто вы

Для входа не нужны ни имя, ни телефон, ни почта, ни пароль. Приложение создаёт анонимную учётную запись Firebase Authentication — это случайный идентификатор устройства, по которому нельзя установить личность. Он нужен только для того, чтобы сервер отличал обращение из приложения от постороннего.

Что хранится

  • Записи бюджета: сумма, дата, категория, тип операции (расход или доход), необязательная заметка и валюта.
  • Настройки бюджета: название, валюта, лимиты по категориям.
  • Код бюджета — случайная строка, по которой участники видят общие записи.

Всё это хранится в Google Cloud Firestore и доступно всем, у кого есть код этого бюджета. Заметка — свободное поле: если написать в ней что-то личное, оно сохранится вместе с записью, поэтому впишите туда только то, что готовы показать участникам бюджета.

Что на устройстве. Список ваших бюджетов, выбранная тема и настройки виджета хранятся только в памяти приложения на телефоне и никуда не отправляются. Удаление приложения стирает их.

Сканер чеков

Когда вы сами выбираете снимок чека или скриншот выписки, приложение уменьшает его и отправляет на наш сервер-посредник (Cloudflare Workers), а тот — в службу распознавания Anthropic (Claude API). В ответ приходят суммы, даты, названия продавцов и предполагаемые категории; вы их проверяете, и только подтверждённое попадает в бюджет.

  • Снимок отправляется только по вашему действию. Приложение не имеет доступа к галерее и не просматривает её: системный выбор фото отдаёт ровно тот файл, который вы указали.
  • Ни сервер-посредник, ни приложение не сохраняют снимки и не ведут журнал их содержимого — изображение живёт только внутри одного запроса.
  • Обработку выполняет Anthropic по условиям своего коммерческого API: данные, переданные через API, не используются для обучения моделей. См. политику Anthropic.

Снимок может содержать что угодно, что попало в кадр. Отправляйте только то, что готовы передать на распознавание.

Кому передаются данные

  • Google (Firebase): хранение записей и анонимный вход — условия.
  • Cloudflare: сервер-посредник сканера — условия.
  • Anthropic: распознавание снимков — условия.

Больше — никому. Ни рекламных сетей, ни систем аналитики, ни трекеров в приложении нет. Данные не продаются и не передаются третьим лицам для их собственных целей.

Как удалить данные

  • Все записи бюджета: кнопка очистки на главном экране. Удаление необратимо и действует для всех участников бюджета.
  • Выйти из бюджета: меню строки в списке бюджетов. Бюджет исчезает с вашего устройства; записи остаются у остальных участников.
  • Всё, что на устройстве: удалите приложение.
  • Бюджет целиком, вместе с анонимной учётной записью: напишите нам по адресу ниже и укажите код бюджета — удалим в течение 30 дней.

Дети

Приложение не предназначено для детей младше 13 лет и не собирает сведения о возрасте.

Изменения

Если что-то в обработке данных изменится, эта страница будет обновлена, а дата редакции — изменена.
